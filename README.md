### Налаштування UV

Цей проєкт використовує [uv](https://github.com/astral-sh/uv) для блискавично швидкого керування залежностями та версій Python, а також `pre-commit` та `ruff` для забезпечення узгодженого форматування коду.

### Передумови

Перш ніж почати, переконайтеся, що на вашому комп'ютері встановлено `uv`. Вам **не** потрібно встановлювати Python вручну; `uv` впорається з цим.

* **macOS/Linux:** `curl -LsSf https://astral.sh/uv/install.sh | sh`
* **Windows:** `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

### Початкове налаштування

Щоб налаштувати локальне середовище, виконайте такі команди:

```bash
# 1. Клонування репозиторію
git clone <your-repo-url>
cd <your-repo-folder>

# 2. Синхронізуйте середовище
# Це автоматично завантажує правильну версію Python, створює .venv,
# та встановлює всі точні залежності з файлу uv.lock.
uv sync

# 3. Встановлення pre-commit hooks
# Це гарантує, що Ruff автоматично форматує ваш код перед кожним комітом.
uv run pre-commit install
```

# Проєкт: «Персональний помічник» (CLI Application)

Необхідно розробити консольний застосунок **«Персональний помічник»**, який дозволяє працювати з контактами, нотатками, задачами та файлами через інтерфейс командного рядка (CLI).

Застосунок повинен підтримувати збереження даних, пошук, редагування, сортування та автоматичну обробку команд користувача.

---

### 1. Книга контактів
Застосунок повинен підтримувати:
* **Додавання контактів** із збереженням таких даних:
  * Ім'я
  * Адреса
  * Номер телефону
  * Email
  * Дата народження
* **Редагування контактів**
* **Видалення контактів**
* **Перегляд списку контактів**
* **Пошук контактів**

### 2. Валідація даних
Під час створення або редагування контактів застосунок повинен:
* Перевіряти правильність номера телефону.
* Перевіряти правильність email.
* Повідомляти користувача про помилки введення.

### 3. Дні народження
Застосунок повинен:
* Виводити список контактів, у яких день народження через задану кількість днів від поточної дати.

### 4. Обрані контакти
Застосунок повинен підтримувати:
* Можливість позначити контакт як *«обраний»*.
* Перегляд списку обраних контактів.

### 5. Робота з нотатками
Застосунок повинен підтримувати:
* Створення нотаток.
* Редагування нотаток.
* Видалення нотаток.
* Пошук нотаток.

### 6. Теги для нотаток
Застосунок повинен підтримувати:
* Додавання тегів до нотаток.
* Пошук нотаток за тегами.

### 7. Робота із задачами (ToDo менеджер)
Застосунок повинен підтримувати:
* Створення задач.
* Редагування задач.
* Видалення задач.
* Перегляд списку задач.
* Пошук задач.

### 8. Статуси задач
Кожна задача повинна мати один із наступних статусів:
* `new` (нова)
* `in progress` (у процесі виконання)
* `done` (виконана)
* `cancelled` (скасована)

Застосунок повинен підтримувати:
* Зміну статусу задачі.
* Фільтрацію задач за статусом.

### 9. Робота з файлами
Застосунок повинен сортувати файли у вказаній директорії за такими категоріями:
* `images` (зображення)
* `videos` (відео)
* `documents` (документи)
* `archives` (архіви)
* `audio` (аудіо)
* `others` (інші типи файлів)

### 10. Пошук дублікатів файлів
Застосунок повинен:
* Знаходити дублікати файлів за їхньою hash-сумою.
* Виводити список однакових файлів.

### 11. Нормалізація файлів
Застосунок повинен:
* Виконувати транслітерацію назв файлів.
* Замінювати некоректні символи.
* Нормалізувати імена файлів.
* Імпорт та експорт

### 12. Імпорт/експорт контактів
Застосунок повинен підтримувати:
* **Експорт контактів** у формати: `JSON`, `CSV`.
* **Імпорт контактів** із форматів: `JSON`, `CSV`.

### 13. Автодоповнення команд
CLI-інтерфейс повинен підтримувати:
* Autocomplete (автодоповнення) команд під час введення.
* Інтерактивні підказки.

### 14. AI-функціонал
Застосунок повинен підтримувати інтелектуальну обробку даних:
* Автоматичну генерацію тегів для нотаток.
* Створення короткого змісту (summary) нотаток.
* AI-пошук по нотатках.

### 15. API-функціонал
Застосунок повинен підтримувати інтеграцію з зовнішніми сервісами для:
* Перевірки курсів валют.
* Перевірки погоди.
